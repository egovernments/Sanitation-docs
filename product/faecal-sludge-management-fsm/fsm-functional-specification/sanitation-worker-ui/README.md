# Sanitation Worker UI

As part of FSM v1.4, sanitation worker related features/screens have been added to the FSM UI. These screens are accessible with current FSM related roles such as FSM\_Admin, Creator, Editor, Collector, etc.

The following screens are available for the sanitation worker UI:

1. [FSM Registry -> Sanitation Worker Tab](fsm-registry.md)
2. [Create Sanitation Worker](create-sanitation-worker.md)
3. [Edit Sanitation Worker](edit-sanitation-worker.md)
4. [Sanitation Worker Details](broken-reference)
5. [Assign Sanitation Workers to FSM Applications (Update to existing screen)](assign-sanitation-workers-to-fsm-applications.md)
