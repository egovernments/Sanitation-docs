# FSM Release Notes

## Release Summary

DIGIT FSM V1.4 has been enhanced to provide the base for features to ensure Sanitation Worker Welfare.\
To know more about DIGIT FSM v1.4 , please follow the [GitBook Link](https://app.gitbook.com/o/-MEQmzNGXk5ajuZujG7E/s/LpfYJCGZoBEmcFf9yWTh/product/faecal-sludge-management-fsm/sanitation-worker-welfare).

### Functional Changes

* Deprecating Driver Registry
* Introduction of Sanitation Worker Registry
* Tagging Sanitation Workers to Service requests.

### Enhancements

| Updated Feature                                                                                                                    | Description                                                                                                                                                                    |
| ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| <p>Maintaining a list of unique sanitation workers in DIGIT Sanitation through a sanitation worker registry</p><p><br></p>         | <ul><li>Viewing list </li><li>Adding a sanitation worker</li><li>Updating details</li><li>Disabling sanitation worker </li><li>Tagging sanitation workers to vendors</li></ul> |
| <p>Recording participation of sanitation workers in service delivery by tagging sanitation workers to requests:</p><p><br><br></p> | <ul><li>Tagging multiple sanitation workers to a request</li><li>Editing tagged sanitation workers</li><li>SMS to sanitation Worker in case of request assignment</li></ul>    |
| Upgrade to inbox from V1 to V2                                                                                                     | <ul><li>To improve performance of the inbox, migrated to version v2 of inbox</li></ul>                                                                                         |
