# Release Notes

## Release Summary

DIGIT Sanitation is enhanced with a new Product -Treatment Quality Monitoring(TQM). The Treatment Quality Monitoring aims to improve the Treatment Quality of plants by ensuring that timely tests are conducted and any deviations are addressed quickly.\
To know more about Treatment Quality Monitoring(TQM) , please follow the [GitBook Link.](https://sanitation.digit.org/v/v1.4/product/treatment-quality-monitoring-tqm)

### New Module

* Treatment Quality Monitoring(TQM)
