# Release Notes

## Release Summary&#x20;

**Introducing New Services for Enhanced Process Quality Management**

1. Process Quality Management (PQM) Service.
2. Process Quality Management (PQM) Anomaly Finder Service.
3. PQM Scheduler (CronJob Scheduler).

Enhancements

1. Sanitation Worker Welfare feature
2. Driver-Individual migrate feature
3. FSM inbox V2

## New ‌Feature Additions <a href="#new-feature-additions" id="new-feature-additions"></a>

<table><thead><tr><th width="233">Feature</th><th>Description</th></tr></thead><tbody><tr><td>Process Quality Management (PQM) Service</td><td><p></p><ul><li>Create, update, and search for process quality monitoring tests.</li><li>Evaluate test values against benchmarks, producing a result (FAIL/PASS) status.</li><li>Test results undergo anomaly analysis for comprehensive insights.</li><li>Plant performance related charts.</li></ul></td></tr><tr><td>Process Quality Management (PQM) Anomaly Finder Service</td><td><p></p><ul><li>Actively monitors anomalies in process quality.</li><li>Notifies relevant user groups promptly for proactive anomaly management.</li></ul></td></tr><tr><td>PQM Scheduler (CronJob Scheduler)</td><td><p></p><ul><li>Automates test scheduling based on environment configuration.</li><li>Triggers schedule APIs from PQM-Service to generate tests.</li><li>Efficiently runs tests at specified intervals, ensuring a configurable solution.</li></ul></td></tr></tbody></table>

## Enhancements

<table><thead><tr><th width="247.5">Feature</th><th>Description</th></tr></thead><tbody><tr><td>Sanitation worker welfare feature</td><td><p>A new worker registry concept has been created.</p><p>The creation of a worker, updation of details, searching and tagging a worker for different operations on sanitation programmes. </p></td></tr><tr><td>Driver-individual migration feature</td><td>The driver-individual migration scripts is responsible for fetching all existing drivers in the system and subsequently generating creates corresponding individuals in the system.<br><br></td></tr><tr><td>FSM Inbox V2</td><td>The inbox for FSM has been upgraded from V1 to V2.</td></tr></tbody></table>
